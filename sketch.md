**1\. PROJECT OVERVIEW & SCOPE OF WORK**

**Objective**

Design and fabricate a postgraduate prototype of an intelligent three-phase load protection system capable of detecting over-current, under-voltage, over-voltage, phase loss, and phase imbalance faults in real time, with automated relay isolation and IoT-enabled online monitoring.

**Deliverables**

* Three-phase voltage and current sensing (3 × ZMPT101B \+ 3 × ACS712 30A)

* ESP32-based protection controller with fault detection firmware

* 4-channel relay module for three-phase load isolation

* OLED local display showing live voltage, current, and fault status

* GSM (SIM800L) module for SMS fault alerts

* IoT dashboard (web \+ mobile) for real-time monitoring

* Enclosure wiring, terminal blocks, DIN rail panel assembly

* Technical documentation: schematics, BOM, test report
